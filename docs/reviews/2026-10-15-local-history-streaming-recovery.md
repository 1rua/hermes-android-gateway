本轮按已批准的本地会话、默认附件保存、公共下载计划恢复 Hermes 插件实现。恢复基线是
`f3935c8a5e65a3fa656cf885979ff326f93f4578`。上轮临时工作区被回收，已产生但未推送的

## 原件生命周期

`HistoryMedia.register` 在 Agent 完成事件发布前校验并采用原件，入站投递在 ACK 前采用。
新原件目录位于 `HERMES_HOME/history-media/open-android-intelligence/owners/<归属摘要>/accounts/<账号摘要>/<会话摘要>/`，
不受宿主 cache 子目录及 Gateway 暂存 TTL 清理影响。采用始终有界复制，核对长度、SHA-256
和来源文件状态，原子移动并同步文件及目录后再登记路径。

附件 ID 继续按账号、会话、消息、原来源路径与摘要生成；记录原始来源映射，在临时源退休
后重试投递保持原 ID。旧引用的原件仍存在且摘要匹配时，第一次读取会采用并保留旧 ID。
已经不存在、损坏或明确删除的原件保留真实元数据并报告不可用；删除记录不能因重试注册复活。
账号清理仅将本插件归属的新旧私有原件目录移至系统临时复核区，不删除其他宿主内容。

原件路径、来源路径和内部采用归属不进入公开附件 part 或 metadata。用户与 Agent 附件都
携带文件名、类型、长度与摘要，手机可在原件不可读时保留文件卡片。

## 签名、授权与响应

metadata、cache-grant、content 三条路径接受 `format=stream-v1`。格式参数参与原有 canonical
签名；metadata/grant 参数闭集只有 format，content 参数闭集是 format 与 grantId。空值、
重复、未知格式及多余字段明确拒绝。无格式参数继续使用原来的 25 MiB 有界 JSON/Base64。

流格式使用 `X-Open-Android-Intelligence-Media-Format: stream-v1`、原 `Content-Type`、
精确 `Content-Length` 与 `Digest: sha-256=<Base64>`。MIME 头包含控制字符或无法编码时，
在发送头之前拒绝。JSON 文件作为原始字节传输，不能与协议外壳混淆。

单用途授权绑定账号、会话、附件、设备、配对 generation、授权 revision、到期和格式。
不绑定 sessionId，从而保留 refresh 后重新发起读取的兼容性。消费签名请求后，迭代器每块
重新打开当前账号核对会话、配对、授权及宿主删除事实，并核对原件身份、长度与最终摘要。
读取采用 64 KiB 缓冲，SQLite、文件校验及迭代读取通过线程执行。发送头前失败返回正常错误
外壳，已发送头之后失败关闭连接，客户端完整性检查拒绝半文件。客户端断开会关闭原件句柄。

## 迁移与交付

不重置账号、配对、登录或宿主会话。旧引用按需迁移，新路径成功后不向旧 cache 原件区写入。
旧原件真正丢失无法恢复，仍明确保留附件信息。此变化不引入公共文件导出行为；公共下载由
Android 的 MediaStore 实现。

插件发行清单、Python 包和原生注册清单同步为 `2.1.1`；协议版本维持 `2.1.0`。
`contract-pin.json` 固定 `851abc44e7ebf5a5aa0ea7ffe311d59be1538058`，CORE 为
`sha256:63223ba149355032800eeae8a9f0827d542bbde7ca9e4eeb19f93df30e7febde`。
附件 Schema 修订要求 App 与插件一起升级。最终实现 SHA、推送后独立审查和 CI 由主代理
在三仓验证完成后填入联合交付记录。
